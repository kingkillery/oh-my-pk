Launch an interactive command in a managed terminal. The `terminal.launchBackend` setting defaults to a new PK-Herdr tab in the caller's workspace, then a psmux session. The new tab does not take focus. If neither can launch, request explicit user approval before Windows Terminal; without interactive approval, stop. Use this tool instead of bash, eval, Start-Process, or wt.exe when opening an interactive terminal. This does not replace ordinary non-interactive command execution.
